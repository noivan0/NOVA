NOVA — Complete System Architecture

Single-agent AI orchestration · KB · Memory · Embedding · Harness Engineering · Provider Layer

Execution Flow

  • • CLI parses harness name + context vars
  • • Config merged from defaults → YAML → env
  • • Harness Loader validates harness.yaml
  • • Checkpoint restored if --resume passed
  • • Orchestrator runs phases sequentially (pipeline) or in parallel batches (fanout)
  • • Quality Gate retries if score < threshold
  • • RunBook handles known failure patterns
  • • Checkpoint saved after every phase
  • • Evolution Log appended on completion
  • • Notifier sends alert; Publisher outputs content

KB + Memory Design

  • • KB = persistent Markdown files across all runs
  • • Memory = in-process context{} dict (one run)
  • • context["_phase_<id>"] carries phase output
  • • context["_fanout_results"] merges parallel phases
  • • KB injected into prompts via {{kb:path/to/page}}
  • • Embedding index enables semantic KB search
  • • Hybrid search: full-text + vector similarity
  • • kb.append_log() maintains activity audit trail
  • • KB survives process restarts and --resume

Harness Engineering

  • • pipeline: P1 output → P2 input → P3 ... (chain)
  • • fanout: A,B,C parallel → merge → synthesis
  • • supervisor: strict quality enforcement pipeline
  • • generative: creative pipeline, tolerant failure
  • • Prompt chaining: {{variable}} + input_files
  • • Quality gate: SCORE: N/100 parsed from LLM
  • • RunBook: symptom → wait:N | notify | skip | abort
  • • Evolution Log learns from every run
  • • nova new <name> scaffolds harness skeleton

Provider Layer

  • • All providers are pluggable — one config line swap
  • • LLM: OpenAI · Anthropic · Ollama · Custom · Echo
  • • GPT-5 (1M ctx), GPT-4.1, o3/o4-mini supported
  • • Claude Opus 4 (claude-opus-4-5) · Sonnet 4 supported
  • • Ollama: local inference, no API key, no cost
  • • Publisher: WordPress · Ghost · Blogger · File
  • • Notifier: Telegram · Slack · Discord · Webhook
  • • Custom: implement LLMProvider.complete() interface
  • • Echo provider: all tests pass with zero API calls
